# VSP

An interactive product website featuring scroll-driven video transitions, a rotating 3D headset, an assembly explorer, and spatial-experience tabs.

## Run locally

Use Node.js and run:

```sh
npm start
```

Open http://127.0.0.1:3000. Browser dependencies are included in `vendor/`.

## Check

```sh
npm run check
node --check product-3d.js
node --check assembly-3d.js
```

The site is static HTML, CSS, and JavaScript. Serve the repository root with a static host to deploy it. Product imagery and model assets depict Apple Vision Pro; generated spatial scenes are creative concepts.
